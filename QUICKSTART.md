--reload --host 0.0.0.0 --port 8000\n```\n\n### Backend Setup (Windows)\n```cmd\ncd backend\nsetup.bat\n.venv\\Scripts\\activate.bat\nuvicorn app.main:app --reload --host 0.0.0.0 --port 8000\n```\n\n### Mobile App Setup (Linux/Mac)\n```bash\ncd mobile-app\nbash setup.sh\nnpx expo start\n# Press 'a' for Android or 'w' for web\n```\n\n### Mobile App Setup (Windows)\n```cmd\ncd start\n```bash\n# Check Python version\npython3 --version  # Should be 3.9+\n\n# Reinstall dependencies\npip install --upgrade -r requirements.txt\n\n# Check port 8000 is free\nlsof -i :8000  # Linux/Mac\nnetstat -ano | findstr :8000  # Windows\n```\n\n### App can't connect to backend\n- Ensure backend is running on http://localhost:8000\n- Check firewall settings\n- Use your actual IP on Android device (not localhost)\n- Verify API_BASE_URL in App.tsx\n\n### SunPower login fails\n- Verify credentials in .env are correct\n- Check internet connection\n- Portals may require browser automation (Selenium)\n- Fallback to mock data if scraper fails\n\n### SmartLife/Tuya not connecting\n- Verify Device ID is correct\n- Check device is online in app\n- Verify region setting (EU/US/CN)\n- May need Tuya Developer API for reliability\n\n## Testing\n\n### Backend Test\n```bash\ncd backend\nbash test.sh\n```\n\n### Manual API Test\n```bash\n# Terminal 1: Backend\nuvicorn
